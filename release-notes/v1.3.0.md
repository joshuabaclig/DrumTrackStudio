## Drum Track Studio now runs on macOS and Linux 🎉

Same app on every platform: paste a YouTube link and get the plain audio, a karaoke track (vocals removed), a drumless track, or a custom mix with any stems removed. It also includes practice-speed copies, a click track and BPM/key detection.

### Windows

Download **`DrumTrackStudio-Setup-1.3.0.exe`** below and run it. Windows may show "Windows protected your PC" because the installer isn't code-signed. Click **More info → Run anyway**. The [README](https://github.com/joshuabaclig/DrumTrackStudio#why-does-windows-show-a-warning) explains why, and how to verify your download against `checksums.txt`.

### macOS (Apple Silicon: M1 or newer)

On macOS the app runs from source, so there's no installer and no "unidentified developer" warning. You'll need [Homebrew](https://brew.sh). In Terminal:

```bash
brew install git ffmpeg uv
git clone https://github.com/joshuabaclig/DrumTrackStudio.git
cd DrumTrackStudio
./setup.sh
./run.sh
```

Intel Macs aren't supported: PyTorch, which does the stem separation, no longer publishes Intel-Mac builds.

### Linux (64-bit, glibc 2.34+: Ubuntu 22.04+, Fedora 35+, Arch, …)

Install `git`, `ffmpeg` and [uv](https://docs.astral.sh/uv/) with your package manager (for example `sudo pacman -S git ffmpeg uv`), then:

```bash
git clone https://github.com/joshuabaclig/DrumTrackStudio.git
cd DrumTrackStudio
./setup.sh
./run.sh
```

Setup also adds **Drum Track Studio** to your app menu.

**Notes for macOS and Linux:**
- `./setup.sh` downloads about 1–2 GB of packages the first time. Most of that is PyTorch.
- To update later, run `git pull` and then `./setup.sh` again.
- To use it from the terminal without the window: `./run.sh "<youtube url>" --mode drumless`. See `./run.sh --help` for all options.

### What's new

- **macOS and Linux support**, through a new cross-platform version of the app built with Python and Qt.
- **Downloads fixed:** yt-dlp is back on its stable release (2026.10.21), which includes the upstream fix for the YouTube "HTTP 403 Forbidden" errors.
- **Updated bundled tools on Windows:** ffmpeg 9.0.2 and deno 2.9.8.
- Fixed the publisher link shown in Windows' Add/Remove Programs.
