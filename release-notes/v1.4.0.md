## Trim the intro, add a lead-in, and one app on every OS

### New: trim & lead-in editor

Some videos open with a sampled intro; others start the song the instant they begin, before you've picked up your sticks. After each download, Drum Track Studio now opens an editor where you can:

- **Scrub** the waveform: click anywhere to move the playhead, scroll to zoom in, play and pause.
- **Cut** a sampled intro or ending by dragging the Start and End handles, typing a time like `0:12.5`, or nudging by 10 ms / 100 ms. "Trim silence" jumps straight to where the sound begins and ends.
- **Add a lead-in gap** of up to 30 seconds of silence before the song, so you have time to get to the kit.
- **Preview** the result: a countdown for the lead-in, then playback from your start point to your end point, exactly as the finished track will sound.

Edits are applied before stem separation, so the karaoke, drumless or custom mix, the practice-speed copies and the click track all line up with the trimmed track, lead-in included. Choose **Keep original** to skip editing for a song, or turn the editor off in Settings. From the terminal, use `--trim-start`, `--trim-end` and `--lead-in` (see `./run.sh --help`).

### Windows now runs the same app as macOS and Linux

The Windows version is now the same Python + Qt app as on macOS and Linux, so every new feature reaches all three at once. It looks and works the same as before, and the installer upgrades your existing install in place, **keeping your settings and output folders**. The old PowerShell version is retired.

### Fixes

- **Opus output works for Karaoke, Drumless and Custom mixes.** It used to fail every time, because the Opus encoder can't encode at 44.1 kHz. Opus files are now always saved at 48 kHz, the rate Opus always plays back at.

### Install

**Windows:** download **`DrumTrackStudio-Setup-1.4.0.exe`** below and run it. Windows may show "Windows protected your PC" because the installer isn't code-signed. Click **More info → Run anyway**. The [README](https://github.com/joshuabaclig/DrumTrackStudio#why-does-windows-show-a-warning) explains why, and how to check your download against `checksums.txt`.

**macOS / Linux:** `git pull`, then run `./setup.sh` again. New here? See the [README](https://github.com/joshuabaclig/DrumTrackStudio#macos-and-linux).
